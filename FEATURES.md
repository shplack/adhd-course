# Features

- [x] Four short, research-informed lessons for parents of adults with ADHD.
- [x] Clear external citations and a medical-information disclaimer.
- [x] One accessible question per module, with feedback and completion tracking.
- [x] Shareable, versioned progress links in path and fragment forms, with invalid-link recovery.
- [x] Keyboard navigation, focus management, semantic structure, and live feedback.
- [x] Unit tests, automated accessibility checks, and keyboard and browser tests.
- [x] Formatting and syntax checks through pre-commit.
- [x] Non-root static container with a read-only filesystem example and security headers.
